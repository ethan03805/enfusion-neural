The IAT evaluation closes after 14.1 minutes: independent CPU parity passes, but synchronized FP32 calls exceed the 10 ms p95 ceiling and raw outputs lose visibility. The fixed bounded version gives no substantial appearance benefit and creates hard mask seams. Preserve the rejected outputs. Do not extend this into another sequence of generic photo-grade searches or optimize a candidate that already fails appearance.

Next is a **60-minute sustained-movement acceptance run** using the working package and the already passable street segment. Freeze a repeated walking/turning route before measurement. Allow one route correction if the pilot fails; retain both attempts. Require at least 120 seconds of logged movement within each 180-second measurement, no prolonged collision, and a declared cross-pass route tolerance. Capture standard, reduced and enhanced passes at 2560 × 1440 with the same scene state and route. Keep all stalls, game and companion presents, processing age, fallback events and recording overhead visible. Verify any new addon through Enfusion Lab before gameplay.

The comparison must retain original elapsed speed and report complete application cadence separately from GPU processing. Review cover, openings, foliage and exposure variation through turns, with a precisely stated review scope. Failures produce a specific retained result, not additional unbounded route searches. This run addresses extended movement and temporal/runtime coverage; it cannot satisfy the unfinished photorealistic appearance gate. A future appearance experiment still needs a concrete, identity-preserving target or new model evidence beyond the rejected grades.
